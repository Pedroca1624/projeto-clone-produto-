# 🚀 SM5 - Do Clone ao Produto Mínimo Viável (MVP+)

## 📝 Visão Geral do Projeto
O **Morphly, Neumorphic Design Studio** é um produto digital original desenvolvido para simplificar a criação de interfaces com a estética *Neumorphism*. O projeto partiu da análise técnica de um produto existente (clone) para a evolução de um MVP funcional com diferenciais próprios.

Este laboratório foi desenvolvido para a disciplina de **Engenharia de Prompt e Aplicações em IA (2026.1)**, focando em como a IA pode acelerar o ciclo de desenvolvimento, da concepção à hospedagem.

## 🧠 Reflexões e Ética no Desenvolvimento
Um dos pilares deste projeto foi a análise crítica sobre o uso de ferramentas generativas:

### O Papel do Desenvolvedor na Era da IA
Com o desenvolvimento assistido por IA, o foco do engenheiro desloca-se da sintaxe para o **pensamento lógico e abstração**. A habilidade essencial torna-se a **comunicação precisa** (requisitos) e a **análise crítica** para validar a originalidade e qualidade do código gerado.

### Inspiração vs. Plágio
Adotamos a diretriz de **Transparência e Transformação**. O uso de IA torna-se plágio quando há reprodução de lógica ou design proprietário sem valor agregado. O Morphly foi construído através da compreensão dos conceitos analisados, garantindo uma versão original e ética.
